10.3 RFCs

RFC73—진짜 알짜배기입니다! 이것들은 인터넷에서 쓰이는 할당 번호와 프로그래밍 API, 프로토콜 등을 설명하는 문서입니다. 여러분의 즐거움을 위해 그중 일부에 대한 링크를 포함했습니다. 팝콘 한 통을 챙기고, 머리를 굴릴 준비를 해 봅시다.

RFC 174 —최초의 RFC입니다. 이 문서는 “인터넷”이 막 태어나던 시점에 어떤 모습이었는지, 그리고 인터넷이 밑바닥부터 어떻게 설계되고 있었는지 엿볼 수 있게 해 줍니다. (물론 이 RFC는 완전히 폐기되었습니다!)
